## Texts cited
For EVERY hadith, Quranic verse, athar, or scholarly quote mentioned in the lesson, add an entry:

### [hh:mm:ss] Short label
- **Text**: the Arabic text if it can be identified (verify it), plus a translation.
- **Type**: hadith / verse / athar / scholar quote / poem.
- **Reference**: for hadith — collection, book/chapter, number (e.g. Sahih al-Bukhari 1, Sahih Muslim 1907),
  narrator chain highlights, and grading (sahih / hasan / da'if, with who graded it). For verses —
  surah name and number:ayah. For scholars — work title and author.
- **Link**: a sunnah.com / quran.com (or other reliable) URL that you actually checked.
- **Confidence**: verified (you found and checked the source) / probable / not found.
  Use web search to verify. Never fabricate a number or a link; say "not found" instead.

## Scholars & works mentioned
- **Name** (death year AH/CE if known) — role in the lesson, works cited.

## Arabic terminology
- **term** (Arabic script) — meaning, as used in this lesson (e.g. mustalah al-hadith terms).
