## Math
The key equations of the lesson in LaTeX (`$...$` / `$$...$$`), each with one line explaining every symbol
and a timestamp where it is introduced.

illustrates it, with a timestamp reference and a one-line note on what to try changing. Keep each under
~60 lines. Mark these "(context)" since they are not from the lecture.

## Papers & resources
Papers, algorithms, and libraries mentioned, with authors/year and a link if well known.
